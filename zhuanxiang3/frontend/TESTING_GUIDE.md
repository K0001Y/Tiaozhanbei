## 问题排查指南

### 常见问题及解决方案

#### 1. 登录问题
**现象**: 登录失败或超时
**排查步骤**:
1. 检查网络连接
2. 确认后端服务状态 (http://localhost:5001/health)
3. 验证数据库连接
4. 查看浏览器控制台错误

**解决方案**:
```bash
# 重启后端服务
cd backend
node app.js

# 检查数据库连接
mysql -u root -p
use medical_assistant;
```

#### 2. 文件上传问题
**现象**: 上传失败或无响应
**排查步骤**:
1. 检查文件格式和大小
2. 确认uploads目录权限
3. 查看服务器磁盘空间
4. 检查multer配置

#### 3. 图片分析问题
**现象**: 分析超时或返回错误
**排查步骤**:
1. 验证图片格式支持
2. 检查图片文件完整性
3. 确认后端AI模块状态
4. 查看服务器日志

#### 4. 数据持久化问题
**现象**: 数据丢失或无法保存
**排查步骤**:
1. 检查zustand存储配置
2. 验证localStorage可用性
3. 确认数据库写入权限
4. 检查事务处理
